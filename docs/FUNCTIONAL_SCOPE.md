# Périmètre fonctionnel

Le flux métier commence par l’import d’un devis : dépôt → prévisualisation → mapping → validation → création atomique du dossier et de ses lignes → préparation des tâches → planification → exécution → contrôle qualité → livraison → clôture.

Les modules préparés sont : dashboard, import de devis, historique des imports, dossiers, ordres de réparation, tâches atelier, planning, pilotage atelier, techniciens, équipes, ressources, qualité, livraison, garantie, réclamations, satisfaction, rapports, paramètres, audit et utilisateurs.

## Hors périmètre

- réception client ;
- gestion des rendez-vous ;
- référentiel clients ;
- référentiel véhicules ;
- pièces de rechange ;
- magasin PDR ;
- commandes et réservations de pièces ;
- création manuelle d’un dossier.
